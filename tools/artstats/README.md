# アセットの実測ツール

ART_PROMPTS.md §5 の判断基準のうち、**目視では判断できない2項目**を数値で出す。

```bash
swiftc -O -o /tmp/artstats tools/artstats/main.swift
/tmp/artstats assets/processed/*.png
```

| 指標 | 合格条件 | 意味 |
|---|---|---|
| 平均明度 | 全体の差が **15 以内** | 1体だけ明るい／暗いと図鑑で浮く |
| アクセント面積 | **3〜6%** | 暖色アクセントの占有率 |
| 占有率 | 参考値 | キャンバスに占める本体の面積 |
| 彩度 | 参考値 | 低彩度パレットから外れていないか |

## なぜ要るか

第1章の4体で、目視では全て合格に見えたが、実測するとネムケだけ明度 127.3
（他3体は 102〜109）で1体だけ明るかった。アクセント面積も 0.1% しかなく、
STYLE SPEC の「ONE warm accent color」と個体ブロックの `pale sickly green`
（寒色）が矛盾していたことが判明した。**どちらも目で見て気付けなかった。**

量産では12体を並べるので、この手のズレは必ず出る。生成のたびに通すこと。
