# アート後処理パイプライン

ART_PROMPTS.md §4 の後処理を機械化したもの。
**統一感はこの工程で決まる。手作業でやると必ずブレるので、全アセットに同じ設定で通す。**

## 使い方

```bash
swiftc -O -o /tmp/artpipeline tools/artpipeline/main.swift

# 1枚
/tmp/artpipeline assets/generated/xxx.png assets/processed/xxx.png

# まとめて
for f in assets/generated/**/*.png; do
  /tmp/artpipeline "$f" "assets/processed/$(basename "$f")"
done
```

## 処理内容

| 順 | 内容 |
|---|---|
| 1 | 四辺から連結した背景を透過にする（内側に穴を開けないため連結性で限定） |
| 1b | 閉じた領域に残った背景を消す（旧仕様の焼き込み画像の救済） |
| 2 | 縁のにじみを削る（背景色が混ざった画素のアルファを落とす） |
| 3 | 外接矩形で切り出し、1024×1024 の中央へ高さ70%で再配置 |
| 4 | ポスタリゼーション（10階調） |

**3 が統一感の要**。生成物はキャンバス内での大きさも位置もばらつくため、
ここで揃えないと図鑑に並べた時に「1体だけ大きい・寄っている」という形で崩れる。

## 調整した経緯

`minimumEnclosedArea = 4000` は実測で決めた。ダラリの白目は背景色とほぼ同一で、
色のしきい値を 12 まで絞っても目が抜けてしまう。一方で目は小さく、腕と胴の隙間や
触手の間は大きいため、**面積で分けている**。

なお 1b は**背景を焼き込んで生成された旧仕様の画像のための救済措置**。
新しいアートは STYLE SPEC どおり透過で生成されるので、この工程は素通りする。

## 確認方法

透過の残留は白背景では判別できない。マゼンタに合成して見ること。
`assets/processed/` の中身を並べて、隙間からマゼンタが見えていれば正しい。
